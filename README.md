A tiny Node program that writes one single word for your Wi-Fi — "Gaslighter" — to `entry.txt` in the output directory, ready for the judge. Five full bars, a cheerful "Connected", every light green, and nothing loads at all: the network swears everything is fine while you are the one left doubting reality. One ordinary word, funny in a single beat because everyone has lived it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
